# 모드별 자세 형상 (해석용)

`metacube_3u_deployed.step`(궤도 전개 형상)을 운용 모드별 자세로 회전한 것.
회전 기준은 형상 bbox 중심이며, 웹 뷰어(운용 자세 탭)와 같은 회전행렬을 쓴다.

월드 축: +x 진행방향 · -z 천저 · 태양(0.62,0,0.78) · 지상국(-0.42,-0.38,-0.82)

| 파일 | 모드 | 맞춘 면 → 목표 | 오일러 XYZ (deg) |
|---|---|---|---|
| `metacube_01_charge_sun.step` | 충전/대기 | pX → (0.62, 0.00, 0.78) | 0.0, -51.5, 0.0 |
| `metacube_02_observe_nadir.step` | 관측 | pZ → (0.00, 0.00, -1.00) | -180.0, 0.0, -180.0 |
| `metacube_03_downlink_gs.step` | 다운링크 | mY → (-0.42, -0.38, -0.82) | 58.2, 14.5, -25.8 |
| `metacube_04_burn_retro.step` | 궤도조정 | mZ → (1.00, 0.00, 0.00) | -0.0, -90.0, 0.0 |

STL 도 같은 이름으로 함께 제공한다(메시 기반 해석용).

생성: `attitude_export.py` — 자세를 바꾸려면 MODES 의 목표 벡터만 고치면 된다.
